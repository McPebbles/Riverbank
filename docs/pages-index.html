Riverbank

A privacy-respecting shopping client for GrapheneOS. One permission, no trackers.

Add this repository to F-Droid

https://OWNER.github.io/REPO/fdroid/repo Fingerprint: PUT_YOUR_SHA256_FINGERPRINT_HERE
  1. Install the F-Droid client (or Droid-ify / Neo Store).
  2. Open Settings → Repositories → +.
  3. Paste the URL above, then check that the fingerprint the client shows matches the one above before you accept it.
  4. Refresh, search for Riverbank, install.

Verify what you installed

apksigner verify --print-certs riverbank-*.apk
